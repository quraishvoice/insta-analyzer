مسح الحساب

بتمسح من الأداة، مع كل بياناته: البوستات، والتعليقات والعملاء، والمبيعات، والأهداف، والأفكار، والمسودات، والتجارب، وصور الستوري.

ربط حساب انستجرام

  1. ادخل developers.facebook.com ← تطبيقاتي ← تطبيقك ← Instagram ← API setup with Instagram login.
  2. في قسم Generate access tokens اضغط Add account وسجّل دخول بحسابك.
  3. اضغط Generate token وانسخ التوكن والصقه هنا.

التوكن يُحفظ على جهازك فقط، والأداة تجدده تلقائياً قبل ما ينتهي.
