# ملف مجالك: `data/profile.json`

الملف يضبط الأداة على مجال المستخدم. أي حقل ما تكتبه ياخذه من `profiles/general.json` (يناسب أي مجال). وتقدر تبدأ من ملف جاهز في `profiles/` بـ `"extends": "<اسم الملف بدون .json>"`. الملفات الجاهزة الحين: `voice-over` (تعليق صوتي وبودكاست).

بعد أي تعديل: تأكد إن الـ JSON سليم وأعد تشغيل الأداة.

## الأسئلة (٥ بالكثير)

1. وش مجالك، ووش تقدم بالضبط؟ (مثال: «أدرّب على التصوير بالجوال»)
2. وش اللي تبيعه؟ دورة، خدمة، منتج، استشارة، اشتراك؟ ووش اسمه؟
3. مين جمهورك؟ (العمر، البلد، الاهتمام)
4. عن وش تنزّل غالباً؟ عطني ٤–٦ أنواع (نصائح، كواليس، آراء عملاء، كوميديا…)
5. لما تبي الناس يطلبون التفاصيل، وش الكلمة اللي تخليهم يكتبونها بالتعليقات؟ (إذا ما عنده، اقترح كلمة قصيرة من مجاله)

وإذا عنده كابشنات قديمة أو حسابه مربوط، تقدر تستنتج كلمات المواضيع من كابشناته بدل ما تسأله. استخدم أعمدة `caption` و`timestamp` من جدول `media` بس.

## الحقول

| الحقل | وش هو | مثال |
|---|---|---|
| `extends` | يبدأ من ملف جاهز في `profiles/` | `"voice-over"` |
| `niche` | اسم مجاله [عربي، إنجليزي] | `["التصوير بالجوال", "phone photography"]` |
| `about` | «عن …» تطلع في قوالب الأسئلة | `["عن التصوير بالجوال", "about phone photography"]` |
| `role` | وش هو بالنسبة لجمهوره | `["مدرب تصوير", "a photography coach"]` |
| `offer` | اللي يبيعه، بأداة التعريف | `["الدورة", "the course"]` أو `["الخدمة", "the service"]` |
| `cta_word` | الكلمة اللي يكتبونها بالتعليقات | `"تصوير"` |
| `emoji` | إيموجي مجاله في القوالب | `"📸"` |
| `business` | وصف نشاطه وجمهوره (يتعبى في نافذة ربط الحساب) | `"تدريب على التصوير بالجوال. الجمهور: …"` |
| `niche_words` | كلمات تدل إن البوست عن مجاله | `["تصوير", "كاميرا", "لقطه", "عدسه"]` |
| `question_words` | سؤال في التعليقات ينحسب «سؤال عميل» بس إذا فيه وحدة منها. فاضي = أي سؤال | `["تصوير", "جوال", "كاميرا", "دوره"]` |
| `offer_words` | كلمات تدل على اللي يبيعه (للدعوة في الكابشن، وأسئلة التسجيل) | `["دوره", "كورس", "ورشه", "خصم"]` |
| `niche_tags` | أجزاء من هاشتاقات مجاله | `["تصوير", "photo", "camera"]` |
| `niche_tag_names` | أمثلة منها للنصائح [عربي، إنجليزي] | `["تصوير، كاميرا", "photo, camera"]` |
| `niche_tag_example` | هاشتاق واحد كمثال | `"#تصوير_جوال"` |
| `topics` | المواضيع (تحت) | |
| `replies` | الرد العام تحت التعليق حسب نوعه: `سعر` و`تسجيل` و`سؤال`. `{user}` = يوزر المعلّق | |
| `info` | أسماء خانات «معلومات العرض»: `العرض: [اسم الخانة, بالإنجليزي, مثال, مثال بالإنجليزي]` و`الموعد: [اسم, بالإنجليزي]` | |
| `objections` | الاعتراضات: `[المفتاح, «الاسم», “English”]` | `["غالية", "«غالية»", "“Too expensive”"]` |
| `dm` | نصوص رسائل الخاص: `first` و`followup1` و`followup2` وكل مفتاح اعتراض | |
| `questions` | أسئلة احتياطية لقالب «أسئلة جمهورك» لين تجي أسئلة حقيقية | |
| `templates` | قوالب `carousel` و`story` و`reel` (اختياري، تحت) | |

### قواعد الكلمات (مهمة)

الكلمات تنقارن بعد ما ينشال التشكيل، و`أ إ آ` تصير `ا`، و`ة` تصير `ه`، و`ى` تصير `ي`، والإنجليزي يصير small. فاكتبها بنفس الشكل: `دوره` مو `دورة`، و`اداء` مو `أداء`.
كل كلمة هي جزء من تعبير منتظم (regex): لا تحط رموز مثل `? + * ( ) [ ] .` إلا إذا تقصدها. مسافة في آخر الكلمة (`"سر "`) تمنع تطابق كلمات أطول.

### المواضيع

```json
{ "name": "نصائح التصوير", "en": "Photo tips", "niche": true, "needs_niche": false, "offer": false, "words": ["زاويه", "اضاءه", "اعدادات", "نصيحه"] }
```

- `niche: true`: موضوع من مجاله (يقارنه بالمحتوى العام في النصائح).
- `needs_niche: true`: ما ينحسب إلا إذا الكابشن فيه كلمة من `niche_words` (للكلمات العامة مثل «نصيحة»).
- `offer: true`: موضوع البيع. واحد بس. خطة النشر تستخدمه لأيام البيع.
- البوست ياخذ الموضوع اللي له أكثر كلمات، ولو تعادلوا ياخذ اللي فوق. اللي ما طابق شي يصير «أخرى».
- ٥–٨ مواضيع، وكل موضوع ١٠–٢٠ كلمة. الأفضل تحط موضوع البيع أول.

### القوالب (اختياري)

القوالب العامة في `profiles/general.json` تشتغل لأي مجال، وفيها رموز تنعبى تلقائياً: `{العرض}` و`{كلمة}` و`{إيموجي}` و`{مجالك}`. اكتب قوالب خاصة بس إذا طلب، أو مجاله واضح وتقدر تكتب أمثلة أقوى. شكلها:

```json
"templates": {
  "carousel": [
    { "key": "mistakes", "name": ["أخطاء شائعة", "Common mistakes"], "goal": "إقناع",
      "desc": ["وصف قصير", "Short description"],
      "slides": [["غلاف", "العنوان", "النص تحت العنوان"], ["الخطأ ١", "…", "…"]] }
  ]
}
```

- `goal`: `جذب` أو `إقناع` أو `بيع`.
- شرائح الكاروسيل والريل: `[الدور، العنوان، النص]`. الستوري: `[الدور، العنوان، النص، الملصق]`، والملصق واحد من `poll` `question` `quiz` `slider` `link` `countdown` `dm` أو فاضي.
- `"dynamic": true` مع `key` = `qa` (كاروسيل) أو `s_ask` (ستوري) يبني القالب من أسئلة التعليقات.
- إذا كتبت `carousel` تنكتب القائمة كاملة (تبدّل القائمة العامة كلها).
